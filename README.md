# Firesat Mission Scheduler Mock

A mock Fire Satellite mission model and scheduling system including IaC components to be deployed via AWS CDK. This module is intended to emulate real industry use cases of Python, AWS CDK, GitHub & GHA, and interactions between available satellites to schedule potential mission actions and provide insights into mission availability.

Contained AWS IaC elements are not actually deployed at this time to adhere to the zero-cost project parameters, but dry run and other mock deployment executions are completed.

Contained libraries, 3rd party utilities, overall design, and other components of consideration will be described in this readme in future changes.
